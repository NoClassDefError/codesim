1. Network model

Every system is a System subclass that builds a list of devices and an RL network and hands them to RLGrid. Units, frames and port conventions are those of the component reference: per unit of the system base, normalized time \(\tau=\omega_b t\), stationary \(\alpha\beta\) frame, generator convention.

1.1 Branch and bus equations

The network has \(n\) buses and \(b\) series RL branches. The incidence matrix \(\mathbf A\in\mathbb R^{n\times b}\) has \(A_{mk}=+1\) at the bus where branch \(k\) leaves and \(-1\) where it enters. Each bus \(m\) holds exactly one voltage port \(V_m\) and one current port \(I_m\). The branch currents are the first \(2b\) states (iga1, igb1, …), followed bus by bus by the states of \(V_m\) and \(I_m\).

$$ \begin{aligned} \mathbf v_m &= \mathbf g_{V_m}\!\left(\mathbf x_{V_m}\right) &&\text{bus voltage from the voltage port}\\ \mathbf i^{I}_m &= \mathbf g_{I_m}\!\left(\mathbf x_{I_m},\mathbf v_m\right) &&\text{current-port injection}\\ L_k\,\dot{\mathbf i}_k &= \sum_m A_{mk}\,\mathbf v_m-R_k\,\mathbf i_k &&\text{branch }k\;(\alpha\beta)\\ \mathbf i^{V}_m &= \sum_k A_{mk}\,\mathbf i_k-\mathbf i^{I}_m &&\text{current delivered by the voltage port} \end{aligned} $$

so each voltage port supplies whatever its bus sends into the branches minus what the current port injects (KCL), and its state equations receive \(\mathbf i^{V}_m\). In compact form, with \(\bar{\mathbf A}=\mathbf A\otimes\mathbf I_2\), \(\dot{\mathbf i}_b=\mathbf L^{-1}(\bar{\mathbf A}^{\top}\mathbf v-\mathbf R\,\mathbf i_b)\). Since the frame is stationary, the branches carry no \(\omega L\mathbf J\) terms. When a device base \((V_b,S_b)\) differs from the system base, its port input and output are scaled by \(V_b/V_{b,sys}\) and \(I_b/I_{b,sys}\) (Inputscale, Outputscale).

The output vector of the grid is \([\mathbf i_b;\mathbf v;\mathbf i^{I}]\), from which calculateNetworkSignals derives the bus injections \(\bar{\mathbf A}\mathbf i_b\), the bus powers \(\underline v_m(\sum_k A_{mk}\underline i_k)^{*}\) and the device powers.

1.2 Passive buses

A bus with None as both its voltage and current device is removed by Kron reduction before the model is built: a degree-2 bus merges its two branches in series (\(R=R_1+R_2\), \(L=L_1+L_2\)); a bus of degree \(d\gt 2\) is replaced by a mesh between its neighbours (star–mesh), \(Z_{ij}=Z_iZ_j\sum_k Z_k^{-1}\), split into \(R=\operatorname{Re}Z_{ij}\), \(L=\operatorname{Im}Z_{ij}\).

1.3 Power flow and initialization

The unknowns are every bus voltage \(V_m\angle\theta_m\) and the \(P_d, Q_d\) of every device. The equations are the bus balances and two device equations each (component reference):

$$ \mathbf Y=\mathbf A\,\operatorname{diag}\!\left(\frac{1}{R_k+jL_k}\right)\mathbf A^{\top},\qquad \underline V_m\left(\mathbf Y\underline{\mathbf V}\right)_m^{*}=\sum_{d\in m}\left(P_d+jQ_d\right),\qquad F_d(P_d,Q_d,V_m,\theta_m)=0 . $$

They are solved from a flat start with scipy.optimize.root (hybrid method). Branch currents are then \((\underline V_{from}-\underline V_{to})/(R_k+jL_k)\), each device builds its initial guess, and the steady state is refined by least squares on \(\mathbf f_{\text{init}}(\mathbf x)=\mathbf 0\) (every state equation except the frame angles). The system raises an error if either residual exceeds residualTolerance.

1.4 Disturbances and clearing

All systems are disturbed through the amplitude reference \(A_{ref}(t)\) of the infinite bus. Two schemes are used.

Time-based profile

Piecewise-linear through the breakpoints (used by every system in "time" mode):

$$ A_{ref}(t)=\operatorname{interp}\Big(t;\; \big(0,1\big),\big(t_{fs},1\big),\big(t_{fc},V_f\big),\big(t_{rs},V_f\big),\big(t_{rc},1\big)\Big), $$

with \(t_{fs}\)=faultStart_s, \(t_{fc}\)=faultComplete_s, \(t_{rs}\)=recoveryStart_s, \(t_{rc}\)=recoveryComplete_s, \(V_f\)=faultVoltage. The breakpoints are passed to the integrator so it restarts at each kink.

Angle-based clearing

With clearMode = "angle" the fault is cleared when the GFM load angle reaches a target, found by the integrator's event detection after an eligibility time; the detected time \(t_{clr}\) is stored as eventTime_s and returned as clearingTime_s.

2. SMIB — single unit on an infinite bus

All SMIB systems use one infinite bus behind a grid impedance set by the short-circuit ratio and the R/X ratio \(\rho\) (on the unit base \(S_b = 8100\) VA, \(V_b = 1\)):

$$ L_g=\frac{1}{\mathrm{SCR}\sqrt{1+\rho^2}},\qquad R_g=\rho\,L_g,\qquad |R_g+jL_g|=\frac{1}{\mathrm{SCR}} . $$

Depending on the unit, the grid impedance is either a network branch (SMIB__SG, whose terminal capacitor is a voltage port) or embedded in the unit (the unit is a current port and the network is a single bus with no branches).
