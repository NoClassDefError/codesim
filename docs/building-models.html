1. Overview

CodeSim models a power network as a set of devices (converters, machines, sources, loads, capacitors) connected by an RL network. You write two kinds of classes:

You writeBase classLives inResponsibility
Componentcodesimpy.core.Devicecodesimpy/components/ Symbolic equations of one device: states, parameters, references, its port output, power-flow and steady-state relations.
Systemcodesimpy.core.Systemcodesimpy/systems/ One concrete study: which devices sit on which bus, the line impedances, base values, references (set-points and fault profiles), default parameters and output signals.

Everything else is generic and comes for free once both classes exist: initialization, EMT simulation, RMS (phasor) simulation and its RMS+Δ correction, small-signal and interaction analysis, the EMT replay decomposition, the symbolic-model pane and the VS Code integration.

What you will build

The worked example is a droop-controlled grid-forming converter GFM_D_N_LC_Droop (internal voltage behind an LC filter, P–f droop with a low-pass power filter, no current limiter) and two systems that use it:

  • SMIB__GFM_D_N_LC_Droop — the converter on an infinite bus;
  • Radial3__GFM_D_N_LC_Droop__GFL_C_F_L — a three-bus radial feeder that also contains an existing grid-following converter, showing how a current-port device gets its bus voltage.

Read sections 2–4 for the concepts and each step, or jump to the complete example and come back when something needs explaining.

2. Core concepts

2.1 Units, time and reference frames

  • Per unit. Each device writes its equations in per unit of its own base (Vb, Sb); the current base is Ib = Sb / (√(3/2)·Vb). When a device's base differs from the system base, RLGrid rescales its port input and output automatically (base conversion). Network impedances R, L are in per unit of the system base.
  • Normalized time. All differential equations use τ = ωb·t with ωb = 2π·frequency_Hz. A derivative dx/dτ therefore has the same numbers as a per-unit model; inductances and capacitances are per-unit reactances and susceptances at nominal frequency. Public times (time_s, breakpoints, references) are in seconds.
  • Frames. The network and every device port use the stationary αβ frame (complex quantities as two real components a, b). Inside a device you usually work in its own rotating dq frame, whose angle θ is a state of the device (a frame angle). You rotate the port current into dq and the output voltage back to αβ.
  • RMS model. The RMS (phasor) model is written in a global DQ frame rotating at 1 pu and is derived automatically from your EMT equations (2.7).

2.2 Voltage ports and current ports

Every device is either a voltage port or a current port. The type decides what the device receives from the network (u) and what it must return (y = g(x, u)):

TypeInput u (αβ)Output g (αβ)Typical devices
"Voltage"ia, ib — the current the device delivers into the network (sum of the branch currents leaving the bus minus the current-port current) va, vb — the bus voltage infinite bus, GFM with its terminal capacitor, line capacitor, synchronous generator
"Current"va, vb — the bus voltage ia, ib — the current injected into the bus GFL converter, loads, induction motor, ZeroCurrent

The output must be algebraic in the states. A voltage port returns its bus voltage as a function of its states (for example a capacitor voltage); it cannot depend on a derivative. A converter whose terminal is an inductor is therefore naturally a current port, unless you embed a capacitor (the …_LC converters) or a quasi-steady impedance (the …_L GFMs).

2.3 Buses and the network

A system is a list of buses. Bus i holds exactly two devices: Vdev[i] (a voltage port) and Idev[i] (a current port). The voltage port sets the bus voltage; the current port injects a current at that voltage.

  • A bus with only a voltage device (a GFM with its capacitor, an infinite bus) gets ZeroCurrent(...) as its current port.
  • A bus with only a current device (a GFL, a load) needs a voltage port. Use the line-charging Capacitor of that bus — physically the shunt capacitance that is always there.
  • A passive junction with no device: put None in both Vdev[i] and Idev[i]. RLGrid removes it by Kron reduction (branch impedances in series or star–mesh). Mixing one None with one device raises each passive node must have both device ports empty.
  • network["A"] is the bus × branch incidence matrix: column k has +1 at the bus the branch leaves and −1 at the bus it enters. R and L are vectors with one value per branch.
  • The branch currents become the first 2·b states of the system: iga1, igb1, iga2, …. Then come, bus by bus, the states of Vdev[i] and of Idev[i].

2.4 Symbols and naming

  • Every symbol of a device is suffixed with "_" + index: a state vCd of a device created with index "gfm" is the SymPy symbol vCd_gfm, and it appears in system.stateNames under that name. Indices must be unique within a system, otherwise two devices share symbols and the model is silently wrong.
  • All symbols are created with real=True. Keep it that way: it lets SymPy differentiate |x| and √x cleanly.
  • Component classes follow Role_Control_Limiter_Filter, e.g. GFM_A_C_LC (grid-forming · virtual admittance + current PI · circular limit · LC filter), GFL_C_F_L. The codes are listed in the docstring of codesimpy/components/__init__.py.
  • System classes follow Network__Unit__Unit, e.g. SMIB__GFM_A_C_LC, CIGRE4__GFM_A_C_LC__GFL_C_F_L. The class name is also the name shown in VS Code.

3. Building a component

A component subclasses Device and implements four methods. The base class builds the symbols, evaluates your equations once and stores them; everything else (Jacobians, compilation, RMS model) is derived from them.

MethodReturnsUsed by
getStateAndOutputEquationsSym()(f, g): state derivatives dx/dτ (one per state) and port output (2 rows)everything
getPowerFlowEquations(V, theta, P, Q)exactly 2 equations = 0power flow inside initialize()
initFromPowerFlow(V, theta, P, Q)initial guess for every local state starting point of the steady-state Newton solve
getFInit()rows of self.f that must be zero in steady stateinitialization; it also defines frame angles and the RMS model

Argument order. The power-flow methods are called as (V, theta, P, Q) — bus voltage magnitude, bus angle, then active and reactive power injected by the device. (The abstract declaration of initFromPowerFlow in device.py names them (P, Q, V, theta), but RLGrid passes them in the order above; follow the existing components.)

3.1 Plan the model on paper

Before writing code, fix four lists. For the droop GFM:

ItemDroop GFMNotes
Port type"Voltage"it holds its terminal capacitor, so its output is the capacitor voltage
States xvCd, vCq, ifd, ifq, Pf, delta, thetathe order is the order of f; theta is the frame angle
Parameters pC, Lf, Rf, mp, wcwith default values in pu of the device base
References urefPref, Vref, wrefset-points the system provides (constants or functions of time)

The equations, in the device frame rotating at wref (with J = [[0,−1],[1,0]]):

  • internal voltage E = Vref·[cos δ, sin δ];
  • filter inductor Lf·dif/dτ = E − vC − Rf·if − ω·Lf·J·if;
  • capacitor C·dvC/dτ = if − ig − ω·C·J·vC, where ig is the port current rotated into dq;
  • power filter dPf/dτ = ωc·(vC·if − Pf);
  • droop dδ/dτ = mp·(Pref − Pf) — the internal frequency is ω + mp(Pref − Pf);
  • frame angle dθ/dτ = ω.

3.3 State and output equations

Return f (one derivative per state, in state order) and g (the port output in αβ, two rows). Use the sym entries of the parameters and the symbols in self.x, self.u, self.uref:

getStateAndOutputEquationsSym (excerpt)
vC = sp.Matrix(self.x[0:2])                 # capacitor voltage, device dq frame
iF = sp.Matrix(self.x[2:4])                 # filter current, device dq frame
Pf, delta, theta = self.x[4:7]
Pref, Vref, w = self.uref
rotation = sp.Matrix([[sp.cos(theta), -sp.sin(theta)],
                      [sp.sin(theta),  sp.cos(theta)]])
iGrid = rotation.T * sp.Matrix(self.u)      # port current: alpha-beta -> dq
...
f = sp.Matrix.vstack(dvC, diF, sp.Matrix([dPf, ddelta, w]))
g = rotation * vC                           # port output: dq -> alpha-beta
return f, g

Rules and good practice

  • Frame angle. If the device has its own rotating frame, include its angle as a state whose derivative is the frame speed (here w). It is never zero in steady state, so it is left out of getFInit — that is how CodeSim recognizes a frame angle.
  • Rotations. R(θ)ᵀ·u converts the αβ port input into dq, R(θ)·v converts back. The rotating-frame cross-coupling is −ω·J·x for an inductor current or capacitor voltage written in dq.
  • Limiters and switches must be smooth. Use expressions SymPy can differentiate everywhere: sp.Abs, sp.sqrt, sp.tanh. The existing devices use (x + |x|)/2 for max(x, 0), a circular limit Imax·i/√((|i|² + Imax² + ||i|² − Imax²|)/2), and (1 + tanh(k·(Vth − |v|)))/2 for mode blending. Avoid Piecewise, Min/Max and Python if on symbols.
  • Size matters. The system Jacobian is derived symbolically with common-subexpression elimination (codesimpy/core/symbolic.py). Repeating a large subexpression is cheap, but keep intermediate quantities as SymPy expressions rather than expanding them by hand.
  • No numbers for tunable values. Write parameters as self.p[name]["sym"] in f and g, so that changing p[name]["num"] later does not require rebuilding the model. Literal constants (1/2, gains you never tune) are fine.

3.4 Power-flow equations

initialize() first solves a power flow. Every bus has unknowns V, θ, and every device has unknowns P, Q (the power it injects). Each device contributes exactly two equations that pin its P and Q (or its voltage):

getPowerFlowEquations
def getPowerFlowEquations(self, V, theta, P, Q):
    Pref, Vref, _ = self.uref                       # references: use the symbols
    C, Lf, Rf = (self.p[name]["num"] for name in ("C", "Lf", "Rf"))   # parameters: numbers
    J = sp.Matrix([[0, -1], [1, 0]])
    vC = sp.Matrix([V, 0])
    iF = sp.Matrix([P, -Q]) / V + C * J * vC
    E = vC + Rf * iF + Lf * J * iF
    return [Pref - P, (E.T * E)[0] - Vref**2]
  • V, theta, P, Q are SymPy symbols; return expressions that are zero at the solution.
  • Reference symbols in self.uref are replaced by their values at the initialization time automatically; use self.p[...]["num"] for parameters.
  • Typical patterns: a PQ device returns [P − Pref, Q − Qref]; a voltage source returns [V − Vref, θ − θref]; a GFM returns [P − Pref, |E|² − Vref²]; ZeroCurrent returns [P, Q]; a shunt capacitor returns [P + Gd·V², Q − ω·C·V²].
  • The whole network must have a slack: at least one device that fixes an angle (the infinite bus does θ = 0).

3.5 Initial state from the power flow

initFromPowerFlow(V, theta, P, Q) receives the power-flow solution of the device's bus as numbers and returns a guess for every local state, in state order. Only a good guess is needed — the exact equilibrium is then found by Newton on the getFInit residuals — but a guess on the correct branch (right angle, right sign of currents) makes initialization fast and reliable.

initFromPowerFlow
def initFromPowerFlow(self, V, theta, P, Q):
    C, Lf, Rf = (self.p[name]["num"] for name in ("C", "Lf", "Rf"))
    J = np.array([[0.0, -1.0], [1.0, 0.0]])
    vC = np.array([V, 0.0])                     # frame aligned with the bus voltage
    iF = np.array([P, -Q]) / V + C * J @ vC
    E = vC + Rf * iF + Lf * J @ iF
    return np.r_[vC, iF, P, np.arctan2(E[1], E[0]), theta]

Choosing the device frame aligned with the bus voltage (θframe = theta) makes v = [V, 0] and i = [P, −Q]/V in dq — the simplest initial guess for most converters.

3.6 Steady-state residuals: getFInit

Return the rows of self.f that are zero at the operating point:

getFInit
def getFInit(self):
    return self.f[:6, :]        # every row except the frame angle theta
  • Return rows taken from self.f (slices or a sp.Matrix of its entries). CodeSim matches each returned row to a state by identity; returning a re-derived or simplified expression raises getFInit() must return equations from the device state derivative vector.
  • Every state whose row you leave out is treated as a frame angle: it is held during initialization, rotated with the DQ frame in the RMS model, and always differential.
  • The number of residuals plus held states must leave a well-posed problem. If your controller has an integrator that is free in steady state (a pure integrator of an error that is zero), keep its row: the Newton solve then fixes the error to zero and the initial guess picks the integrator value.
  • A device without states returns self.f (empty).

3.7 RMS model

The RMS (phasor) model is generated from your EMT equations. In it, branch currents and most device states become algebraic (0 = Fa); only frame angles and the states you list stay differential:

class attribute
class GFM_D_N_LC_Droop(Device):
    rmsDynamicStateNames = ("delta", "Pf")   # local names, without the index suffix
  • List the slow states: synchronization angles (delta), power filters, PLL integrators (xPLL), outer-loop integrators. Fast electrical states (filter currents, capacitor voltages) and fast inner-loop integrators should stay algebraic.
  • A name that is not one of the device's states raises unknown RMS dynamic states.
  • The default getRMSEquationsSym() subtracts 1 from each frame-angle row (the angle is measured relative to the 1 pu DQ frame) and keeps all other rows. Override it only if your device needs different phasor equations.
  • Check the result with system.simulateRMS(...)["differentialStateNames"] and in the VS Code symbolic pane (RMS → F), where differential states are highlighted.

3.8 Base conversion

If a device is created with a base different from the system base (e.g. a 5 MVA converter in a 25 MVA system), RLGrid calls device.convertToAnotherBase(Vb_system, Sb_system). The default implementation keeps your equations in the device base and sets Inputscale / Outputscale, which scale the port signals on the way in and out. Nothing to do for converters.

Override it in two cases, as the existing devices do:

  • Sources that define the system voltage (Infbus) or placeholders (ZeroCurrent): override with return None so no scaling is applied.
  • Passive elements (Capacitor): convert the parameter values themselves (e.g. C /= Zbase_ratio) and update self.Vb, self.Sb, self.Ib.

3.9 Register the component

  1. Save the class in codesimpy/components/<name>.py with from ..core import Device.
  2. Import and export it in codesimpy/components/__init__.py:
    codesimpy/components/__init__.py
    from .gfm_d_n_lc_droop import GFM_D_N_LC_Droop
# ... and add "GFM_D_N_LC_Droop" to __all__
  3. Optional: the topology view picks an icon from the class name (OutputJsonFactory.deviceAppearance): names containing gfm/vsg → GFM converter, gfl/pll → GFL converter, motor, capacitor, load/zip/cpl, sg… → generator, Infbus → grid; anything else is a generic device. Extend that function only if you need a new category.

4. Building a system

A system subclasses System, provides defaultParameters, builds its devices and network in __init__, and implements calculateSignals.

4.1 Default parameters

defaultParameters(overrides=None) is a static method that returns the complete parameter dictionary. The VS Code panel lists these parameters and lets the user edit them; edited values come back as overrides, so derived values must be computed after applying the overrides.

defaultParameters (excerpt)
@staticmethod
def defaultParameters(overrides=None):
    p = {"Vbase": 1, "Sbase": 1e6, "frequency_Hz": 50, "SCR": 3, "XR": 10,
         "Pref": 0.8, "Vref": 1.05, "wref": 1,
         "faultVoltage": 0.5, "faultStart_s": 0.2, "faultComplete_s": 0.201,
         "recoveryStart_s": 0.35, "recoveryComplete_s": 0.351,
         "validationTime_s": 1.0, "outputStep_s": 1e-4, "residualTolerance": 1e-6}
    p.update(overrides or {})
    p["Lg"] = 1 / (p["SCR"] * np.sqrt(1 + 1 / p["XR"]**2))     # derived after overrides
    p["Rg"] = p["Lg"] / p["XR"]
    p["breakpoints_s"] = [p["faultStart_s"], p["faultComplete_s"],
                          p["recoveryStart_s"], p["recoveryComplete_s"]]
    return p

4.2 Devices and network

Create the devices, place them on the buses and describe the branches:

devices and network (excerpt)
gfm = GFM_D_N_LC_Droop(p["Vbase"], p["Sbase"], "gfm")
source = Infbus(p["Vbase"], p["Sbase"], "grid")
devices = {
    "Vdev": [gfm, source],                                  # voltage port of bus 0, 1
    "Idev": [ZeroCurrent(p["Vbase"], p["Sbase"], "gfm_zero"),
             ZeroCurrent(p["Vbase"], p["Sbase"], "grid_zero")],
    "gfm": gfm, "source": source,                           # named handles (optional)
}
network = {
    "A": np.array([[1.0], [-1.0]]),     # one branch: bus 0 -> bus 1
    "R": np.array([p["Rg"]]), "L": np.array([p["Lg"]]),
    "busNames": ["GFM terminal", "Infinite bus"],
}
  • Vdev, Idev and busNames have one entry per bus, in the same order as the rows of A.
  • Extra keys in devices are not used by the core; they are a convenient way to reach devices later (self.devices["gfm"]).
  • To tune a device for this system, set device.p[name]["num"] after creating it and before super().__init__, e.g. gfl.p["KpPll"]["num"] = 0.2.
  • Devices may use their own rating, e.g. GFM_A_C_LC(1, 5e6, "vsg") in a 25 MVA system; see base conversion.

4.3 References

The reference map gives a value to every reference symbol of every device, keyed by the symbol name (str(device.uref[k])). Values are numbers or functions of time in seconds:

references (excerpt)
references = {
    str(gfm.uref[0]): p["Pref"],                          # Pref_gfm
    str(gfm.uref[1]): p["Vref"],                          # Vref_gfm
    str(gfm.uref[2]): p["wref"],                          # wref_gfm
    str(source.uref[0]): lambda t: gridVoltage(t, p),     # Aref_grid(t): the fault profile
}
  • A missing reference raises a KeyError during construction.
  • Time-varying references should be continuous ramps between breakpoints (the fault edges above last 1 ms); list the ramp edges in breakpoints_s so the integrator does not step over them.
  • system.setReference(name, value) changes one later; system.getReference(t) evaluates all of them.

4.5 Events (optional)

For state-dependent events (e.g. clearing a fault when an angle crosses a value), set:

  • eventStartTime_s: time from which the event is armed (None disables events);
  • eventHandler(time_s, state): a method returning a value whose zero crossing triggers the event;
  • eventDirection: −1 falling, 0 either, +1 rising;
  • eventName, and read eventTime_s (the detected time; inf if not triggered) inside your reference functions to start the recovery.

SMIB__GFM_A_C_LC with clearMode="angle" is a complete example. The RMS simulation does not support state-triggered events.

4.6 Output signals

calculateSignals(time_s, state, networkSignals) returns a dictionary of signals for plots and snapshots. Start from busSignals and add your own:

calculateSignals
def calculateSignals(self, time_s, state, networkSignals):
    signals = self.busSignals(networkSignals, np.arange(self.rlGrid.n), self.rlGrid.n - 1)
    gfm = self.devices["gfm"]
    state = np.asarray(state)
    column = lambda name: state[:, self.stateNames.index(f"{name}{gfm.index}")]
    signals["delta"] = column("delta")
    signals["filterCurrentMagnitude"] = np.hypot(column("ifd"), column("ifq"))
    return signals
  • busSignals(networkSignals, busIndices, referenceBus) returns busVoltageMagnitude, busVoltageAngleDeg (relative to referenceBus), activePower, reactivePower, lineCurrentMagnitude, plus busNames and finalValues.
  • networkSignals also contains the complex busVoltage, branchCurrent, busCurrent, device currents and powers, and referenceTrace.
  • Arrays have one row per time sample (state is samples × states). The function is called on whole runs and on streamed chunks, so it must not assume a fixed length.
  • The VS Code plots group signals automatically: |V|, I, P/Q and θ become the four default plots; every state is available as well.

4.7 Register the system

  1. Save it as codesimpy/systems/<name>.py, importing devices with from ..components import … and from ..core import System.
  2. Import it in codesimpy/systems/__init__.py and add the class name to __all__. The VS Code backend builds its system list from __all__; nothing in the extension needs to change.

5. Complete worked example

Four files: the component, the two systems and the registration lines. These are the exact files that were installed into a copy of codesimpy and run to produce the numbers quoted on this page.

5.1 Component

codesimpy/components/gfm_d_n_lc_droop.py
"""GFM_D_N_LC_Droop: droop-controlled GFM, internal voltage behind an LC filter."""

import numpy as np
import sympy as sp

from ..core import Device


class GFM_D_N_LC_Droop(Device):
    """GFM · D: internal voltage directly behind the filter, P-f droop with a
    low-pass power filter · N: no current limiter · LC: the device holds its
    terminal capacitor, so it is a voltage port."""

    # Local states that stay differential in the RMS model, besides the frame
    # angle theta (which is always differential). All others become algebraic.
    rmsDynamicStateNames = ("delta", "Pf")

    def __init__(self, Vb: float, Sb: float, index: str) -> None:
        super().__init__(
            Vb, Sb, "Voltage", index,
            # Parameters: name -> default numeric value (pu on this device's base).
            {"C": 0.05, "Lf": 0.08, "Rf": 0.01, "mp": 0.05, "wc": 0.05},
            # States, in the order used by f, initFromPowerFlow and getFInit.
            ("vCd", "vCq", "ifd", "ifq", "Pf", "delta", "theta"),
            # References (inputs from the system): set through the system's reference map.
            ("Pref", "Vref", "wref"),
        )

    def getStateAndOutputEquationsSym(self):
        C, Lf, Rf, mp, wc = (self.p[name]["sym"] for name in ("C", "Lf", "Rf", "mp", "wc"))
        vC = sp.Matrix(self.x[0:2])                 # capacitor voltage, device dq frame
        iF = sp.Matrix(self.x[2:4])                 # filter-inductor current, device dq frame
        Pf, delta, theta = self.x[4:7]
        Pref, Vref, w = self.uref
        J = sp.Matrix([[0, -1], [1, 0]])            # 90-degree rotation
        rotation = sp.Matrix([[sp.cos(theta), -sp.sin(theta)],
                              [sp.sin(theta), sp.cos(theta)]])
        iGrid = rotation.T * sp.Matrix(self.u)      # port current: alpha-beta -> dq
        E = Vref * sp.Matrix([sp.cos(delta), sp.sin(delta)])
        diF = (E - vC - Rf * iF) / Lf - w * J * iF
        dvC = (iF - iGrid) / C - w * J * vC
        dPf = wc * ((vC.T * iF)[0] - Pf)            # low-pass filtered active power
        ddelta = mp * (Pref - Pf)                   # droop: internal frequency w + mp (Pref - Pf)
        f = sp.Matrix.vstack(dvC, diF, sp.Matrix([dPf, ddelta, w]))
        g = rotation * vC                           # port output: terminal voltage, alpha-beta
        return f, g

    def getPowerFlowEquations(self, V, theta, P, Q):
        # Two equations in the bus voltage V, angle theta and the injected P, Q.
        # References appear as their symbols; parameters as numbers.
        Pref, Vref, _ = self.uref
        C, Lf, Rf = (self.p[name]["num"] for name in ("C", "Lf", "Rf"))
        J = sp.Matrix([[0, -1], [1, 0]])
        vC = sp.Matrix([V, 0])
        iF = sp.Matrix([P, -Q]) / V + C * J * vC
        E = vC + Rf * iF + Lf * J * iF
        return [Pref - P, (E.T * E)[0] - Vref**2]

    def initFromPowerFlow(self, V, theta, P, Q):
        # Initial guess of every local state, in state order. The frame is aligned
        # with the bus voltage (theta = bus angle), so vC = [V, 0].
        C, Lf, Rf = (self.p[name]["num"] for name in ("C", "Lf", "Rf"))
        J = np.array([[0.0, -1.0], [1.0, 0.0]])
        vC = np.array([V, 0.0])
        iF = np.array([P, -Q]) / V + C * J @ vC
        E = vC + Rf * iF + Lf * J @ iF
        return np.r_[vC, iF, P, np.arctan2(E[1], E[0]), theta]

    def getFInit(self):
        # Steady-state residuals: every row of f except the frame angle theta,
        # whose derivative (w) is never zero.
        return self.f[:6, :]

5.3 Single machine on an infinite bus

codesimpy/systems/smib_gfm_d_n_lc_droop.py
"""SMIB__GFM_D_N_LC_Droop: one droop GFM with its LC filter on an infinite bus."""

import numpy as np

from ..components import GFM_D_N_LC_Droop, Infbus, ZeroCurrent
from ..core import System


def gridVoltage(t, p):
    """Infinite-bus voltage magnitude: a sag to faultVoltage and its recovery."""
    fall = np.clip((t - p["faultStart_s"]) / (p["faultComplete_s"] - p["faultStart_s"]), 0, 1)
    rise = np.clip((t - p["recoveryStart_s"]) / (p["recoveryComplete_s"] - p["recoveryStart_s"]), 0, 1)
    return 1 - (1 - p["faultVoltage"]) * (fall - rise)


class SMIB__GFM_D_N_LC_Droop(System):
    """SMIB · GFM_D_N_LC_Droop: one droop GFM with its LC filter on an infinite bus."""

    @staticmethod
    def defaultParameters(overrides=None):
        p = {
            "Vbase": 1, "Sbase": 1e6, "frequency_Hz": 50,
            "SCR": 3, "XR": 10, "Pref": 0.8, "Vref": 1.05, "wref": 1,
            "faultVoltage": 0.5, "faultStart_s": 0.2, "faultComplete_s": 0.201,
            "recoveryStart_s": 0.35, "recoveryComplete_s": 0.351,
            # Required by the VS Code backend (EndTime_s, OutputStep_s, ResidualTolerance):
            "validationTime_s": 1.0, "outputStep_s": 1e-4, "residualTolerance": 1e-6,
        }
        p.update(overrides or {})
        # Derived values are recomputed from the (possibly overridden) inputs.
        p["wBase"] = 2 * np.pi * p["frequency_Hz"]
        p["Lg"] = 1 / (p["SCR"] * np.sqrt(1 + 1 / p["XR"]**2))
        p["Rg"] = p["Lg"] / p["XR"]
        p["breakpoints_s"] = [p["faultStart_s"], p["faultComplete_s"],
                              p["recoveryStart_s"], p["recoveryComplete_s"]]
        return p

    def __init__(self, p):
        gfm = GFM_D_N_LC_Droop(p["Vbase"], p["Sbase"], "gfm")
        source = Infbus(p["Vbase"], p["Sbase"], "grid")
        devices = {
            # Bus i holds Vdev[i] (voltage port) and Idev[i] (current port).
            "Vdev": [gfm, source],
            "Idev": [ZeroCurrent(p["Vbase"], p["Sbase"], "gfm_zero"),
                     ZeroCurrent(p["Vbase"], p["Sbase"], "grid_zero")],
            # Extra keys are named handles for your own code (e.g. calculateSignals).
            "gfm": gfm, "source": source,
        }
        network = {
            "A": np.array([[1.0], [-1.0]]),         # branch 1: GFM terminal (+1) -> infinite bus (-1)
            "R": np.array([p["Rg"]]), "L": np.array([p["Lg"]]),
            "busNames": ["GFM terminal", "Infinite bus"],
        }
        references = {                              # one entry per device reference symbol
            str(gfm.uref[0]): p["Pref"],
            str(gfm.uref[1]): p["Vref"],
            str(gfm.uref[2]): p["wref"],
            str(source.uref[0]): lambda t: gridVoltage(t, p),   # time-varying: a callable of t (s)
        }
        base = {"Vbase": p["Vbase"], "Sbase": p["Sbase"], "frequency_Hz": p["frequency_Hz"]}
        super().__init__(type(self).__name__, network, devices, base, references)
        self.parameters, self.parameterNames = p, list(p)
        self.nonEditableParameterNames = ("Vbase", "Sbase", "frequency_Hz")

    def calculateSignals(self, time_s, state, networkSignals):
        # Standard bus signals (|V|, line currents, P, Q, angles relative to the last bus) ...
        signals = self.busSignals(networkSignals, np.arange(self.rlGrid.n), self.rlGrid.n - 1)
        # ... plus your own: one row per time sample.
        gfm = self.devices["gfm"]
        state = np.asarray(state)
        column = lambda name: state[:, self.stateNames.index(f"{name}{gfm.index}")]
        signals["delta"] = column("delta")
        signals["filterCurrentMagnitude"] = np.hypot(column("ifd"), column("ifq"))
        return signals

5.4 Radial feeder with a GFL

The GFL (GFL_C_F_L) is a current port, so bus 2 gets the line capacitor as its voltage port. The PLL and current-loop gains are set to the values used by the CIGRE systems: with the class defaults the PLL mode of this feeder is weakly unstable (two poles at about +0.013 ± j0.70 pu), which the small-signal analysis reports immediately.

codesimpy/systems/radial3_gfm_d_n_lc_droop.py
"""Radial3__GFM_D_N_LC_Droop__GFL_C_F_L: infinite bus - bus 2 (line capacitor + GFL) - bus 3 (droop GFM)."""

import numpy as np

from ..components import Capacitor, GFL_C_F_L, GFM_D_N_LC_Droop, Infbus, ZeroCurrent
from ..core import System
from .smib_gfm_d_n_lc_droop import SMIB__GFM_D_N_LC_Droop, gridVoltage


class Radial3__GFM_D_N_LC_Droop__GFL_C_F_L(System):
    """Radial · bus 2: line capacitor (voltage port) + GFL_C_F_L (current port) · bus 3: droop GFM."""

    @staticmethod
    def defaultParameters(overrides=None):
        overrides = dict(overrides or {})
        for name, value in (("Idref", 0.5), ("Iqref", 0.0), ("Cline", 0.02)):
            overrides.setdefault(name, value)
        return SMIB__GFM_D_N_LC_Droop.defaultParameters(overrides)

    def __init__(self, p):
        gfm = GFM_D_N_LC_Droop(p["Vbase"], p["Sbase"], "gfm")
        gfl = GFL_C_F_L(p["Vbase"], p["Sbase"], "gfl")
        # Device parameters are plain numbers in device.p[name]["num"]; set them
        # before System.__init__ (these are the gains used by the CIGRE systems).
        for name, value in (("KpPll", 0.2), ("KiPll", 0.02), ("Kpcc", 0.3), ("Kicc", 1.0)):
            gfl.p[name]["num"] = value
        # A GFL is a current port: its bus still needs a voltage port. Here it is
        # the line-charging capacitor of bus 2.
        lineC = Capacitor(p["Vbase"], p["Sbase"], "bus2C")
        lineC.p["C"]["num"] = p["Cline"]
        source = Infbus(p["Vbase"], p["Sbase"], "grid")

        def zero(name):
            return ZeroCurrent(p["Vbase"], p["Sbase"], name)

        devices = {
            "Vdev": [source, lineC, gfm],
            "Idev": [zero("grid_zero"), gfl, zero("gfm_zero")],
            "gfm": gfm, "gfl": gfl, "source": source,
        }
        network = {
            # Columns are branches: 1 = grid -> bus 2, 2 = bus 2 -> bus 3.
            "A": np.array([[1.0, 0.0], [-1.0, 1.0], [0.0, -1.0]]),
            "R": np.array([p["Rg"], p["Rg"] / 2]), "L": np.array([p["Lg"], p["Lg"] / 2]),
            "busNames": ["Infinite bus", "2", "3"],
        }
        references = {
            str(gfm.uref[0]): p["Pref"], str(gfm.uref[1]): p["Vref"], str(gfm.uref[2]): p["wref"],
            str(gfl.uref[0]): p["Idref"], str(gfl.uref[1]): p["Iqref"],
            str(source.uref[0]): lambda t: gridVoltage(t, p),
        }
        base = {"Vbase": p["Vbase"], "Sbase": p["Sbase"], "frequency_Hz": p["frequency_Hz"]}
        super().__init__(type(self).__name__, network, devices, base, references)
        self.parameters, self.parameterNames = p, list(p)
        self.nonEditableParameterNames = ("Vbase", "Sbase", "frequency_Hz")

    def calculateSignals(self, time_s, state, networkSignals):
        # Angles relative to bus 0, the infinite bus.
        return self.busSignals(networkSignals, np.arange(self.rlGrid.n), 0)

6. Running it from Python

From the repository root (so that codesimpy is importable):

session.py
import numpy as np

from codesimpy.systems import SMIB__GFM_D_N_LC_Droop

# 1. Parameters and model (the symbolic model is built here, once per structure).
p = SMIB__GFM_D_N_LC_Droop.defaultParameters({"SCR": 3})
system = SMIB__GFM_D_N_LC_Droop(p)
print(system.stateNames)       # ['iga1', 'igb1', 'vCd_gfm', ..., 'theta_gfm', 'theta_grid', 'A_grid']
print(system.referenceNames)   # ['Pref_gfm', 'Vref_gfm', 'wref_gfm', 'Aref_grid']

# 2. Operating point: power flow -> initFromPowerFlow -> Newton on the getFInit residuals.
op = system.initialize(ResidualTolerance=p["residualTolerance"])
print("residual", op["initialization"]["residualInfNorm"])

# 3. EMT simulation (time in seconds; the breakpoints restart the solver at the fault edges).
t = np.arange(0.0, p["validationTime_s"], p["outputStep_s"])
emt = system.simulate(t, InitialState=op["state"], Breakpoints_s=p["breakpoints_s"], saveSnapshot=False)
print(emt["signals"]["busVoltageMagnitude"].shape)   # (samples, buses)

# 4. Small-signal and interaction analysis at the operating point.
analysis = system.smallSignal.analyze(op)
print("unstable poles:", analysis["unstablePoleCount"])
interaction = system.smallSignal.interactionAnalysis()
print(interaction["blockNames"])     # one block per device + 'Network / source'

# 5. RMS (phasor) simulation and its first-order RMS+Delta correction.
rms = system.simulateRMS(t, InitialState=op["state"], Breakpoints_s=p["breakpoints_s"])
corrected = system.correctRMS(rms, cutoff_Hz=1000)
print(rms["differentialStateNames"])  # frame angles + rmsDynamicStateNames

# 6. EMT component: replay the fast states with the slow states held on the simulated trajectory.
dec = system.transientVoltage.decompose(
    emt, ["delta_gfm", "Pf_gfm"], busNames=["GFM terminal"], timeWindow_s=(0.35, 0.45))
print("max replay error", np.abs(dec["replayError"]).max())
  • initialize() raises RuntimeError: initialization failed when the residual exceeds the tolerance; see troubleshooting.
  • simulate(...) returns time_s, state, signals (your calculateSignals), referenceTrace, events and the wall time. Pass saveSnapshot=False outside VS Code to avoid writing codegen/*-snapshot.json.
  • Eigenvalues are in normalized time: multiply by ωb for rad/s; the mode table already contains frequencies in Hz and damping ratios.
  • For systems with a GFL, include its PLL states (theta_…, xPLL_…) among the slow states of decompose; otherwise the replay error is large by construction.

7. Using it in VS Code

  1. Restart the Python backend (power button in the topology toolbar) or reload the window. The resident backend imports codesimpy once, so new files are only seen after a restart.
  2. Select the system in the dropdown. It is listed under its class name; the topology view shows its buses, devices and branches.
  3. Edit parameters in the system parameter editor. Edited values are passed to defaultParameters(overrides); derived values are recomputed.
  4. Run EMT (time-domain simulation, streamed live), RMS (phasor simulation, ▾ for the RMS+Δ correction), Small signal and Interaction from the Signals toolbar.
  5. Inspect the model in the Small signal tab → Symbolic model: the states x and inputs u, then f, g and the Jacobian A of the EMT model, and F, A_RMS, B_RMS of the RMS model, one device block at a time. This is the quickest way to check that your equations were assembled as intended.

The backend talks to the extension in UTF-8. Symbols such as Δ or ∂ in labels are fine; if you start the backend yourself from a console with another encoding, set PYTHONUTF8=1.

8. Testing

A focused test catches most mistakes early: an operating point that is not an equilibrium, a model that does not simulate, or a wrong RMS partition.

codesimpy/tests/test_droop_example.py
import unittest

import numpy as np

from codesimpy.systems import SMIB__GFM_D_N_LC_Droop


class DroopExampleTests(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.p = SMIB__GFM_D_N_LC_Droop.defaultParameters()
        cls.system = SMIB__GFM_D_N_LC_Droop(cls.p)
        cls.op = cls.system.initialize(ResidualTolerance=cls.p["residualTolerance"])

    def test_operating_point_is_an_equilibrium(self):
        self.assertLess(self.op["initialization"]["residualInfNorm"], 1e-8)
        # The GFM delivers its reference power.
        signals = self.system.calculateNetworkSignals(
            np.array([0.0]), self.op["state"][None, :], self.system.getReference())
        self.assertAlmostEqual(signals["busPower"][0, 0].real, self.p["Pref"], places=6)

    def test_short_simulation(self):
        t = np.linspace(0, 0.01, 11)
        result = self.system.simulate(t, InitialState=self.op["state"], saveSnapshot=False)
        self.assertEqual(result["state"].shape, (t.size, len(self.system.stateNames)))
        self.assertTrue(np.isfinite(result["signals"]["busVoltageMagnitude"]).all())

    def test_small_signal_and_rms(self):
        self.assertEqual(self.system.smallSignal.analyze(self.op)["unstablePoleCount"], 0)
        t = np.linspace(0, 0.05, 51)
        rms = self.system.simulateRMS(t, InitialState=self.op["state"])
        self.assertIn("delta_gfm", rms["differentialStateNames"])
        self.assertLess(np.max(rms["algebraicResidual"]), 1e-6)


if __name__ == "__main__":
    unittest.main()

11. Checklists

New component

  • Port type chosen; output algebraic in the states.
  • States, parameters and references listed; one consistent state order.
  • f has one row per state; g has two rows in αβ.
  • Smooth limiters only; parameters as symbols.
  • getPowerFlowEquations(V, theta, P, Q) returns exactly two equations.
  • initFromPowerFlow(V, theta, P, Q) returns every state in order.
  • getFInit returns rows of self.f; only frame angles are left out.
  • rmsDynamicStateNames lists the slow states.
  • convertToAnotherBase overridden if it is a source or a passive element.
  • Exported in components/__init__.py.

New system

  • defaultParameters includes validationTime_s, outputStep_s, residualTolerance, breakpoints_s; derived values computed after overrides.
  • One voltage port and one current port per bus (ZeroCurrent, Capacitor, or None/None).
  • Unique device indices.
  • A is bus × branch with ±1; R, L, busNames sized to match.
  • Every reference symbol in the reference map; breakpoints at every reference ramp.
  • parameters, parameterNames set after super().__init__.
  • calculateSignals returns busSignals plus custom signals.
  • Exported in systems/__init__.py; a test initializes, simulates and runs small signal.
